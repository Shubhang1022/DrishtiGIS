### A UAV dataset for urban scene understanding from India


> This survey has been carried out under [Water4Change project](https://w4cproject.org/), a joint collaboration between 🇮🇳 and 🇳🇱. The drone survey has been conducted with assistance from [AccionLAND](https://accionland.com).

---

- **DSM**: This directory contains digital surface models.
- **Image**: This directory contains orthorectified RGB images.
- **Label**: This directory contains raster annotations.
- **Vector**: This direcory contains vector annotation and area of interest in `GPKG` format. The spatial outline of the of training and test samples are available in the `Sample_Distribution.gpkg` vector file. Additionally, a `KMZ` file of the scene has been provided for visualization purposes. 
- **VRT**: These files creates virtual raster mosaic on the fly.
	+ **\_POSIX**: The filenames ending with this tag indicates compatibility with UNIX like operatibg systems.
	+ **\_NT**: The filenames ending with this tag indicates compatibility with Windows operating system.
- **Image Format**: All images are in `GeoTiff` format with `EPSG:32643` coordinate reference system.
- **GDAL**: Recommended `GDAL 3.6.0+` with `libtiff 4.3.0+`, `ZSTD` and `JXL` support.
- **License**: The `LICENSE.txt` file contains the mandatory license agreement. If you download or use this dataset you automatically agree with this license agreement.
- **Cite**: If you use this datset consider appropriately citing it.
- **Data Config**: Relative paths to the`Train` and `Test` samples are available in `Data_Config.json` file in machine readable `JSON` format. Template of the config is shown below:
